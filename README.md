# 阴阳结界异闻录 ~ Mythic Spell Barrier

一款基于东方神话与阴阳玄幻背景的 **东方Project (Touhou) 风格 2D 弹幕射击游戏**。

本项目为**纯原生 HTML5 / JavaScript 单文件游戏**，无需安装任何开发环境、依赖包或外部音频素材，双击 `index.html` 即可在任意现代网页浏览器（Chrome / Edge / Firefox / Safari）中即刻畅玩！

---

## 🌟 游戏亮点与核心机制

- **经典车万双重攻击形态**：
  - **默认高速模式**：发射五向扇形符纸散弹，覆盖范围广，适合清理道中小怪。
  - **低速微调模式（按住 Shift 键）**：
    - 主角移动速度降低，胸口显现**红色核心判定点（Hitbox）**，方便精细躲避密布弹幕。
    - 攻击自动切换为【阴阳·火凤集中阵】，高伤害集中平行符文极速轰炸 Boss。
- **擦弹系统 (Graze System)**：
  - 当敌方弹幕擦过主角判定点边缘时，触发金色光华与清脆擦弹音效，增加擦弹计数与得分。
- **符卡绝招 / 爆弹 (Spell Card / BOM)**：
  - 按 `X` 键、`K` 键或 `Space` 空格键释放【秘术·太极八卦大结界】。
  - 全屏八卦法阵扩张，瞬间清空全屏敌弹并转化为积分分点，给予主角完全无敌时间。
- **动态难度递增系统 (Rank System)**：
  - 游戏难度随你的得分增长（每 10,000 分升一阶），弹幕花纹与发射密度会逐步丰富。
  - **平缓手感保证**：弹幕飞行速度始终保持在平缓悠扬区间，绝不提速，体验纯正弹幕穿缝美学。
- **全新独立 UI 死亡结算与复活**：
  - 挂掉后弹出清晰的居中 UI 弹窗：
    - 🟢 **【💥 原地满血复活】**：支持鼠标左键直接点击或按 `Z` / `Space` / `Enter` 键一秒满血复活，附带清屏与 4 秒无敌保护。
    - ⚪ **【🏠 退出游戏 / 返回主页】**：返回标题画面。
- **纯代码 Web Audio 音效引擎**：
  - 内置基于浏览器原生 `AudioContext` 实时合成的射击声、擦弹声、爆弹声、被弹（Pichuun~）声与符卡音效，零资源依赖。

## 🎮 操作指南

| 操作指令 | 键盘按键 | 效果说明 |
| :--- | :--- | :--- |
| **移动控制** | `方向键 ↑ ↓ ← →` / `W A S D` | 控制阴阳师八向平稳移动 |
| **法术射击** | `Z` / `J` / `鼠标左键` | 连续发射阴阳法术弹幕 |
| **低速专注** | `Shift` (长按) | 显现**中心红色 Hitbox 判定点**，减速微调并集中火力 |
| **符卡绝招 (BOM)** | `X` / `K` / `Space 空格` | 释放全屏太极八卦阵，清空全屏敌弹并获得无敌保护 |
| **暂停 / 继续** | `P` / `Esc` | 暂停游戏 |
| **原地复活** | `鼠标点击按钮` / `Z` / `Space` / `Enter` | 死亡弹窗出现时一秒满血复活 |
| **退出主页** | `鼠标点击按钮` / `Esc` | 死亡弹窗出现时返回游戏主界面 |

## 🚀 启动与游玩方式

1. 打开本项目所在目录：`C:\Users\USER\Documents\danbakugame\`
2. **直接双击 `index.html` 文件**（或右键选择使用 Chrome / Edge 浏览器打开）。
3. 点击界面中的 **【⛩️ 驱魔出阵 (开始游戏)】** 按钮即可开启弹幕对决！

## 📤 Git 提交与远程推送指南

如果你希望将本项目代码托管到 GitHub 或 Gitee：

1. **安装 Git 工具**（如电脑尚未安装）：
   - 从 [Git 官网 (https://git-scm.com/)](https://git-scm.com/) 下载并安装 Git。
2. **在项目目录下打开终端 (PowerShell 或 CMD)，运行以下命令**：

```bash
# 1. 初始化 Git 仓库
git init

# 2. 将所有文件添加到暂存区
git add .

# 3. 提交本地版本
git commit -m "feat: initial commit for touhou style mythic danmaku game"

# 4. 关联你的 GitHub / Gitee 远程仓库地址 (请将 URL 替换为你的仓库链接)
git remote add origin https://github.com/你的用户名/你的仓库名.git

# 5. 推送到远程主分支
git branch -M main
git push -u origin main
```
